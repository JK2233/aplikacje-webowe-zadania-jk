# Aplikacje webowe zadania
Aplikacje webowe wykonywywane w ramach zajęć klasy 5 techinikóm.

## Uruchamianie projektów
- W foldereach w tym repo znajdują się zadania
- Zadanie sa z regóły projektami React stworzonymi w Javascript
- Aby uruchomić jeden z projektów wystarczy w jego foldeże uruchomić komędy
```bash
npm install
npm run dev
```
Aplikacje działają pod `http://localhost:5173`.

## Struktura projektów
Każdy projekt znajduje się w swoim folderze, niektóre są dodatkowo podzielone na theoretical i practical, wtedy practical jest zadaniem do wykonania samodzielnego a theoretical jest przepisany z tablicy na lekcji.
